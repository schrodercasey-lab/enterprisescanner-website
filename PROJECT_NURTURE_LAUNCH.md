## 🔧 IF THINGS GO WRONG

### **Common Issues:**

**1. Import Errors**
```
ImportError: No module named 'aws_hunter_unified'
```
**Fix:** Make sure aws_hunter_unified.py is in workspace directory

**2. AWS Credentials Error**
```
Unable to locate credentials
```
**Fix:** Run `aws configure` or set AWS environment variables

**3. Memory Not Loading**
```
No previous AWS patterns in memory
```
**Fix:** This is expected on first intelligent hunt! The Oct 27 scan was blind, so memory is empty. We'll need to import Oct 27 findings manually (Task #5).

**4. Hunter Not Found**
```
ValueError: Unknown hunter type: aws
```
**Fix:** Check jupiter_unified_hunter.py imports AWSHunter correctly
